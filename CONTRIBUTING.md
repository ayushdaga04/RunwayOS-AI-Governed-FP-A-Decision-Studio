# Contributing

RunwayOS is a portfolio demonstration, but improvements are welcome.

1. Create a focused branch.
2. Keep all finance calculations deterministic and separate from narrative generation.
3. Add or update tests whenever financial logic changes.
4. Do not add claims about realized business results; all company data is synthetic.
5. Run `npm test` and `npm run build` before opening a pull request.

Changes to runway, cash, MRR, payroll or variance calculations should also update `docs/FINANCE_MODEL.md`.
