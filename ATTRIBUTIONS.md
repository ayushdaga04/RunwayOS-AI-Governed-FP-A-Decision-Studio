# Design and research references

This project was implemented as original code. No third-party repository code was copied into the application.

The product direction was informed by publicly visible patterns in:

- Etherlabs cashflow forecasting engine — forecast/scenario architecture (MIT-licensed reference)
- Burnless — non-destructive financial scenario interaction concept
- Shadcn Fintech — modern finance-product visual patterns
- HarishKrishnaan FP&A dashboard — conventional FP&A report coverage

All finance logic, copy, synthetic data, interaction behavior and visual styling in RunwayOS were authored specifically for this portfolio project.
